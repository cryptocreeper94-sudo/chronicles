PERMISSION MAPPING (Now Flexible)

Your permissions "snippets:read, snippets:write" now work because I added aliases:

  snippets:read  → maps to read:code  ✓
  snippets:write → maps to write:code ✓
  logs:read      → maps to read:logs  ✓
  logs:write     → maps to write:logs ✓

═══════════════════════════════════════════════════════════════════════════════
ENDPOINTS FOR SNIPPETS
═══════════════════════════════════════════════════════════════════════════════

POST /api/ecosystem/snippets
  → Push a code snippet
  Body: { name, description, code, language, category, tags, isPublic, version }

GET /api/ecosystem/snippets
  → Get all snippets
  Query params: ?category=authentication&language=typescript

GET /api/ecosystem/snippets/:id
  → Get specific snippet by ID
