AUTHENTICATION
═══════════════════════════════════════════════════════════════════════════════

All authenticated endpoints require HMAC-SHA256 signature in headers:

Headers:
  X-DarkWave-App-ID: <your_app_id>
  X-DarkWave-Signature: <hmac_sha256_signature>
  X-DarkWave-Timestamp: <unix_timestamp>
  Content-Type: application/json

Signature Generation (Node.js):
  const crypto = require('crypto');
  const timestamp = Date.now().toString();
  const payload = timestamp + JSON.stringify(body);
  const signature = crypto
    .createHmac('sha256', YOUR_API_SECRET)
    .update(payload)
    .digest('hex');

PUBLIC ENDPOINTS (No Auth Required)
═══════════════════════════════════════════════════════════════════════════════

GET /api/ecosystem/apps
  → List all connected apps in the ecosystem

GET /api/ecosystem/status
  → Check hub connection status

GET /api/ecosystem/contracts
  → List all smart contracts

GET /api/ecosystem/contracts/:name
  → Get specific contract (e.g., /contracts/darkwave-token)

GET /api/ecosystem/docs
  → List all whitepapers and documentation

GET /api/ecosystem/docs/:name
  → Get specific document (e.g., /docs/darkwave-token-whitepaper)

GET /api/ecosystem/app-metadata
  → Get rich metadata for all apps (icons, gradients, descriptions)

═══════════════════════════════════════════════════════════════════════════════
EXAMPLE: SYNC WORKERS (AUTHENTICATED)
═══════════════════════════════════════════════════════════════════════════════

const crypto = require('crypto');

const APP_ID = 'dw_app_yourappid';
const API_SECRET = 'your_api_secret';

const body = { workers: [{ name: 'John Doe', email: 'john@example.com' }] };
const timestamp = Date.now().toString();
const payload = timestamp + JSON.stringify(body);
const signature = crypto.createHmac('sha256', API_SECRET).update(payload).digest('hex');

const response = await fetch('https://orbitstaffing.io/api/ecosystem/sync/workers', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-DarkWave-App-ID': APP_ID,
    'X-DarkWave-Signature': signature,
    'X-DarkWave-Timestamp': timestamp
  },
  body: JSON.stringify(body)
});
